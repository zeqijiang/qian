# 游戏设计总览

## 项目定位
以《神秘复苏》世界观为灵感的 2D 横版竞技格斗游戏原型。  
**个人学习 / 私人 Demo**；若未来商业化需重新审查 IP 与素材授权，或转为原创灵异世界观。

## 核心体验关键词
灵异 · 厉鬼 · 驾驭 · 复苏 · 鬼域 · 压制 · 代价

## 玩法支柱
1. 传统 2D 横版格斗（移动/跳/冲刺/攻/防/连段/硬直/击飞）
2. **灵异值**：技能资源，攻击/受击回复
3. **厉鬼复苏值**：强力技能的代价条，高风险高回报
4. 角色专属机制（杨间：鬼眼/鬼影/鬼域/鬼手）

## 当前原型范围（Phase 0）
- 训练场 1v1
- 杨间（玩家） vs 占位敌人（AI）
- 移动 / 跳 / 冲刺 / 格挡 / 轻重空攻 / 受击 / 连击 / 能量 / 调试

## 控制
见 `docs/TECHNICAL_DESIGN.md`

## 开发原则
先玩法，后美术；先框架，后角色；先单机，后联网；先一个角色，后角色池；先可玩，再完善。
