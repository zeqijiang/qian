# 角色设计

## 角色 01：杨间

**定位**：综合型 / 高机动 / 灵异控制  
**核心机制**：鬼眼、鬼影、鬼域、鬼手、厉鬼复苏

| 属性 | 值 |
|------|-----|
| HP | 1000 |
| 攻击 | 1.05 |
| 防御 | 1.00 |
| 移动速度 | 300 |
| 跳跃 | -640 |
| 冲刺 | 560 / 0.18s |

### 被动：鬼眼
- 战斗中探测/锁定/技能强化基础（Phase 7 实装表现）

### 普攻
- 轻攻击 → 轻攻击 → 轻攻击 → 重攻击 基础连段

### 技能一：鬼手
近距离控制/抓取，中等伤害

### 技能二：鬼影
本体 + 鬼影延迟追加攻击

### 技能三：鬼域
展开领域：移速强化、技能强化、限制敌人

### 特殊：鬼眼压制
短时锁定，可与其他技能连携

### 奥义：多重灵异压制
鬼域 → 鬼眼 → 鬼影 → 鬼手 → 连续攻击 → 终结

### 厉鬼复苏
复苏值越高，攻击强化越明显，同时更危险

### 弱点
高机动但非最高单发伤害；复苏失控有风险

### 操作难度
★★★☆☆
