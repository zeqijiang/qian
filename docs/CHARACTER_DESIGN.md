# 角色设计

## 角色 01：杨间

**定位**：综合型 / 高机动 / 灵异控制  
**核心机制**：鬼眼、鬼影、鬼域、鬼手、厉鬼复苏

| 属性 | 值 |
|------|-----|
| HP | 1000 |
| 攻击 | 1.05 |
| 防御 | 1.00 |
| 移动速度 | 300 |
| 跳跃 | -640 |
| 冲刺 | 560 / 0.18s |

### 被动：鬼眼
- 鬼域中眼部与光环表现强化；复苏触发时攻击 ×1.15

### 普攻
- 轻攻击 → 轻攻击 → 轻攻击 → 重攻击 基础连段

### 技能一：鬼手（U）
近距高硬直抓取，命中后将对手拉向自己。灵异 20

### 技能二：鬼影（I）
本体一击 + 约 0.24s 后鬼影延迟追击。灵异 25

### 技能三：鬼域（O）
6s 领域：自身移速 ×1.25、伤害 ×1.2；敌方移速 ×0.75。灵异 35，冷却 4s

### 特殊：鬼眼压制（H）
不可防、短时锁定目标约 0.75s。灵异 30

### 奥义：多重灵异压制（P）
需满 100 灵异。展开鬼域 → 4 连击 → 终结击飞。复苏 +18

### 厉鬼复苏
复苏值越高，攻击强化越明显，同时更危险

### 弱点
高机动但非最高单发伤害；复苏失控有风险

### 操作难度
★★★☆☆

### 键位（原型）
| 键 | 技能 |
|----|------|
| U | 鬼手 |
| I | 鬼影 |
| O | 鬼域 |
| H | 鬼眼压制 |
| P | 奥义 |
| 训练 F7 | 无限灵异（测奥义） |

## 角色 02：叶真

**定位**：近战 / 高防 / 霸体爆发  
**核心**：铁壁无敌窗、霸体吃刀、高单发伤害

| 属性 | 值 |
|------|-----|
| HP | 1150 |
| 攻击 | 1.15 |
| 防御 | 1.20 |
| 移动速度 | 250 |

### 技能
| 键 | 技能 | 效果 |
|----|------|------|
| U | 铁冲 | 带霸体的突进重击 |
| I | 崩拳 | 高伤击飞 |
| O | 铁壁 | 约 1.2s **无敌**（自身输出略降） |
| H | 霸体重击 | 超级霸体大伤害 |
| P | 绝对反击 | 满 100 灵异：短无敌 + 多段 + 终结 |

### 弱点
腿短、依赖贴脸；铁壁后输出真空
